What I did

Built the full marketing stack from scratch across 7 APAC markets for a mostly B2B customer base, briefing and managing external agencies and partners to deliver across every channel. Designed a GEO/AI-search visibility system that took a new domain from zero to 30,000+ impressions and earned a cited-source position in Perplexity for category queries, backed by backlink growth through outreach and digital PR.

Shipped bulk SEO through the Shopify Admin API instead of editing pages by hand, codifying rules into version-controlled standards with Claude Code and MCP that contractors and agency partners now run directly, so the system ran without me as the bottleneck. Ran paid media across Google, LinkedIn and Meta Ads with budget ownership, and built HubSpot reporting syncs that the sales team adopted for their own pipeline reporting.

How this was built

AI search engines like Perplexity don't rank pages the way Google does. They write an answer and cite sources that clearly show expertise on the topic. So instead of writing for keywords, I restructured content around the questions someone would actually ask an AI assistant: clear topic clusters, direct answers up front, and structured data that says exactly what each page is an authority on. I also fixed the technical basics AI crawlers rely on to trust a source: internal linking, clean information architecture and consistent E-E-A-T signals. Because this covered a whole domain rather than a few pages, I built it as a documented ruleset in Claude Code, so every new piece of content followed the same standard automatically.
